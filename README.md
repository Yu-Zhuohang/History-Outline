# 考研政治·史纲时间线地图

把考研政治「中国近现代史纲要」的核心事件按年份竖排在左侧，点击某个节点，右侧地图定位到事件发生地并弹出地点说明，下方同步显示该事件的背景、内容、意义和易考提示。

纯静态页面，不需要后端、不需要数据库、不需要 API Key。

---

## 一、如何打开

**必须用本地服务器打开，不能直接双击 `index.html`。**

原因：页面用 `fetch` 读取 `data/events.json`，浏览器对 `file://` 协议下的本地文件读取有安全限制，直接双击会看到「事件数据加载失败」的提示。

### 最省事：双击「启动.bat」（Windows）

双击项目根目录的 `启动.bat`，它会自己找 Python、起一个本地服务器，并自动打开浏览器。黑窗口关掉就停止。

> 首次运行 Windows 可能弹出「Windows 已保护你的电脑」——点「更多信息」→「仍要运行」即可，这是本地批处理脚本的常规提示。

### 手动启动（任意系统）

在本项目目录下任选一种方式：

```bash
# 方式一：Python（装 Python 后一般都有）
python -m http.server 8000

# 方式二：Node.js
npx serve .

# 方式三：VS Code 装 Live Server 插件，右键 index.html → Open with Live Server
```

然后浏览器访问 `http://localhost:8000`。

### 部署到线上

部署到 GitHub Pages、Netlify、Vercel 等静态托管平台时，直接把整个目录上传即可，无需额外配置，也不需要 `启动.bat`。

## 三、交互说明

| 操作 | 效果 |
|---|---|
| 点击左侧节点 | 节点高亮 → 地图平滑飞至该地并弹出标记 → 下方面板更新考点 |
| Tab 键聚焦后按 Enter / 空格 | 与点击等效（键盘可用） |
| 手机端点击节点 | 除上述效果外，页面自动滚动到地图区域 |
| 地址栏带 `?id=事件id` | 打开即定位到该事件，例如 `index.html?id=1935-zunyi-huiyi` |

事件 id 见 `data/events.json` 的 `id` 字段，格式为「年份-事件简称」。

## 四、数据结构

`data/events.json` 是对象数组，按 `year` 升序排列，每个对象字段固定：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一标识，格式「年份-事件简称」，如 `1921-zhonggong-yida` |
| `year` | number | 年份，用于排序 |
| `date` | string | 具体时间，如 `1921年7月` |
| `title` | string | 事件全称 |
| `locationName` | string | 地点（多地事件用 `/` 分隔） |
| `lat` / `lng` | number | 纬度 / 经度（WGS84，保留 4 位小数） |
| `mapNote` | string | 地图弹窗里的一句话地点说明 |
| `keyPoints` | object | 考点四段式：`background`、`content`、`significance`、`examTips` |

左侧时间线显示的是「简称」：`title` 末尾的括号注释、`locationName` 中的括号说明会在列表中自动省略，点开后在面板里显示全称。

新增事件只要往数组里追加对象，无需改 HTML/JS；改成 `year` 后顺序会自动重排。

## 五、地图说明

- **地图库**：Leaflet 1.9.4，CDN 引入（jsDelivr，失败时自动换 staticfile 备用源）。地图库加载失败时页面不会白屏，只是不显示地图，时间线和文字讲解照常可用。
- **底图**：OpenStreetMap 体系的公开瓦片，主源 `tile.openstreetmap.de`，连续失败后自动切换到 `tile.openstreetmap.fr/hot`（HOT 风格）。两者都是 WGS84 / Web 墨卡托，与数据经纬度同坐标系，**不需要 API Key**。
- **为什么不用高德 / 百度瓦片**：它们的底图是 GCJ-02 坐标系，与数据里的 WGS84 坐标存在几百米偏移，放大后标记会偏离真实位置。若你确实想换中文底图，需要先把全部坐标转换成 GCJ-02（或用高德的坐标转换接口），否则会出现偏移。
- 标记用内联 SVG/CSS 绘制（`divIcon`），不依赖 CDN 上的图片文件，断网也不会出现裂图图标。

## 六、已知限制

1. **事件数据需要人工校对**：31 个事件的时间、地点、考点表述由模型整理，正式复习前请对照权威教材核对，尤其是「意义」「易考提示」这类容易出错的表述。
2. 部分事件用城市中心坐标近似（如三大战役取北京、太平天国取南京），`mapNote` 里已注明；多地点事件只标注主要发生地。
3. 时间线为单页一次性渲染 31 个节点，事件规模再大（100+）时需要改成分章节折叠。
4. 部分事件的字段表述仍建议对照教材复核，见 `校对记录.md` 第三节。
